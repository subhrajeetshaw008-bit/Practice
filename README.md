# Practice

My personal practice repository for learning **Python** and **C** — small programs and exercises solved while working through core programming concepts.

## Structure

```
Practice/
├── C/                              # C practice programs
├── Python/
│   ├── 01_practice/                # Basics
│   ├── 02_control_flow_and_loops/  # if/else, for, while, match-case
│   ├── 06_OOPS/                    # Classes, objects, constructors
│   └── ...
├── LICENSE
└── README.md
```

Folders are numbered roughly in the order topics were learned, so browsing top to bottom follows a rough learning path.

## Topics covered so far

**Python**
- Basics / fundamentals
- Control flow: `if`/`else`, `for`/`while` loops, `match`-`case`
- Object-Oriented Programming: classes, objects, constructors

**C**
- Basic input/output programs (`scanf`/`printf`)
- Simple calculations (e.g. volume calculator)

## Running the code

**Python**
```bash
python Python/<folder>/<file>.py
```

**C**
```bash
gcc C/<file>.c -o C/<file>
./C/<file>
```
