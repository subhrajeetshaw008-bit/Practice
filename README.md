## 🧠 What's this repo about?

This is where I break things, fix them, and (occasionally) figure out *why* they broke. A running logbook of my coding journey — fundamentals, control flow, loops, OOP, and whatever comes next.

No production code here — just honest, unfiltered practice. 💪

## ▶️ Running the code

**🐍 Python**
```bash
python Python/<folder>/<file>.py
```

**🇨 C**
```bash
gcc C/<file>.c -o C/<file>
./C/<file>
```

**➕ C++**
```bash
g++ C++/<folder>/<file>.cpp -o C++/<folder>/<file>
./C++/<folder>/<file>
```
